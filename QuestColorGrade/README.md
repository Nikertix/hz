# Цветокор AR — цветокоррекция passthrough (AR/MR) для Meta Quest 3S / 3 / Pro / 2

Приложение для гарнитуры: вы видите реальный мир через камеры (passthrough), а поверх — небольшая
панель, где в реальном времени меняются **контраст, яркость, насыщенность, гамма, температура и тинт**.
Настройки сохраняются между запусками.

> **Важное ограничение платформы.** Сторонние приложения на Quest не могут менять картинку *других*
> приложений и системного интерфейса. Цветокоррекция здесь применяется к изображению с камер
> (passthrough) внутри этого приложения — именно для такого сценария Meta даёт API.
> Коррекцию делает сам системный компоновщик, поэтому задержки практически нет.

## Что проверено, а что нет

Проверено на ПК: математика цветокоррекции (набор автотестов + визуальное сравнение до/после),
вёрстка панели (программный рендер с тем же кодом раскладки), синтаксис всего C++ кода.
**Не проверено:** сборка APK и запуск на реальной гарнитуре — в среде, где писался проект, не было
Android SDK/NDK и доступа в интернет. Если сборка или запуск дадут ошибку — пришлите текст ошибки
(лог сборки или текст в красной плашке внутри приложения) — исправим.

## Как получить APK

### Способ A. Облачная сборка на GitHub (ничего устанавливать не нужно)

1. Зарегистрируйтесь на <https://github.com> (бесплатно) и создайте репозиторий: **New repository** →
   имя, например, `QuestColorGrade` → **Create repository**.
2. Распакуйте архив проекта. На странице нового репозитория нажмите **uploading an existing file** и
   перетащите **всё содержимое** папки `QuestColorGrade` (включая скрытую папку `.github`) →
   **Commit changes**.
   *Если папка `.github` не загрузилась:* **Add file → Create new file**, в имени файла напишите
   `.github/workflows/build-apk.yml` (слэши создадут папки), вставьте содержимое одноимённого файла из
   архива → **Commit changes**.
3. Откройте вкладку **Actions**. Если GitHub просит разрешить workflow — подтвердите. Выберите
   **«Собрать APK»** → **Run workflow**. Сборка идёт 10–20 минут.
4. Когда появится зелёная галочка, откройте этот запуск и внизу в разделе **Artifacts** скачайте
   `QuestColorGrade-apk`. Внутри zip — файл **`QuestColorGrade.apk`**.

### Способ B. Android Studio (на ПК)

Установите Android Studio, откройте папку проекта, дождитесь синхронизации (она сама скачает NDK 27
и CMake 3.22) и выберите **Build → Build APK(s)** (вариант *release*). APK появится в
`app/build/outputs/apk/release/app-release.apk`. Подпись отладочная — для установки на Quest этого достаточно.

## Установка на Quest

1. Включите **режим разработчика**: приложение Meta Horizon на телефоне → Устройства → ваша гарнитура →
   Настройки гарнитуры → Режим разработчика.
2. Подключите гарнитуру к ПК по USB, разрешите отладку в гарнитуре и установите APK одним из способов:
   - **SideQuest** → «Install APK file from folder on computer», или
   - командой `adb install -r QuestColorGrade.apk`.
3. Запуск: Библиотека → фильтр **«Неизвестные источники»** → **«Цветокор AR»**.

## Управление (контроллеры Touch)

| Действие | Кнопка |
|---|---|
| Выбрать параметр | стик ↑ / ↓ |
| Изменить значение | стик ← / → (удерживайте **триггер** — подстройка в ~8 раз точнее) |
| Сбросить выбранный параметр | **A** |
| Сбросить все параметры | **Y** |
| Оригинал / с коррекцией (сравнение) | **X** (на панели загорается «ОРИГИНАЛ») |
| Скрыть / показать панель | **B** (при показе панель появляется перед вами) |
| Вернуть панель перед собой | нажатие **правого стика** |
| Базовый ↔ расширенный режим | нажатие **левого стика** |

Работает любой стик (левый или правый). Управление жестами рук не поддерживается — нужны контроллеры.

## Режимы

- **Расширенный (3D-LUT, по умолчанию)** — расширение Meta `XR_META_passthrough_color_lut`.
  Доступны все 6 параметров: яркость (экспозиция), контраст, насыщенность, гамма, температура, тинт.
- **Базовый** — системный фильтр `XR_FB_passthrough` (яркость / контраст / насыщенность по формулам
  Meta). Включается автоматически, если LUT не поддерживается, или вручную (левый стик, нажатие).
  Значения в двух режимах не совпадают один в один — формулы разные.

## Если что-то не так

- Красная плашка «Ошибка» поверх панели — запишите её текст.
- Лог приложения: `adb logcat -s QuestColor`.
- Странные цвета в расширенном режиме — нажмите левый стик (переход в базовый режим) и сообщите об этом.
- Чёрный фон вместо камер — проверьте, что passthrough не отключён в настройках гарнитуры и в
  пространстве задана граница.

## Состав проекта

```
app/src/main/cpp/main.cpp           OpenXR-приложение (NativeActivity, passthrough, ввод, кадровый цикл)
app/src/main/cpp/grading.h          параметры, расчёт 3D-LUT, значения для базового режима, сохранение
app/src/main/cpp/ui.h               раскладка панели (слайдеры, текст) - без зависимостей от GL
app/src/main/cpp/gles_renderer.h    отрисовка панели в OpenGL ES 3
app/src/main/cpp/font_data.h        метрики шрифта (генерируется tools/gen_font.py)
app/src/main/assets/font.r8         растровый атлас шрифта (кириллица + латиница + стрелки)
tools/test_grading.cpp              автотесты математики цветокоррекции (запуск на ПК)
tools/host_preview.cpp              отрисовка панели в картинку на ПК
tools/gen_font.py                   генератор атласа шрифта
.github/workflows/build-apk.yml     облачная сборка APK
```

Лицензии: шрифт Liberation Sans — SIL OFL 1.1 (в проект вшиты только растровые глифы);
OpenXR loader — Apache 2.0 (подключается из Maven Central).
